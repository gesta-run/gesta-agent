# 安装完成后重启客户端设计

## 状态

方案已确认，按 macOS/Linux 首版范围实现。

## 目标

Gesta Agent 安装或升级成功后，让新安装的 Codex 和 Claude Code Hook
及时生效，同时避免意外中断用户工作：

- 停止任何客户端前必须征得用户确认；
- 用户确认后立即执行重启；
- 用户拒绝时输出明确的手动重启提示；
- 非交互安装保持安全，并兼容自动化流程。

## 当前行为

原 POSIX 安装脚本只支持通过 Codex 专用参数重启 macOS Codex Desktop，且提示读取
标准输入，使用文档中的 `curl | bash` 安装方式时会被跳过。Codex CLI 和
Claude Code CLI 原本都不会重启。

Windows 安装脚本暂不纳入首版。

## 用户流程

仅在 Hook 安装和 Daemon 健康检查全部成功后执行重启流程。

1. 在 macOS/Linux 检测目标用户正在运行的客户端：
   - Codex Desktop（macOS 上的 `ChatGPT.app`）；
   - 带终端（TTY）的 Codex CLI；
   - 带终端（TTY）的 Claude Code CLI。
2. 如果至少有一个受影响客户端正在运行，展示检测结果并只询问一次：

   ```text
   是否立即重启正在运行的 AI 客户端，让新的 Gesta Hook 生效？[y/N]
   ```

3. POSIX 从控制终端 `/dev/tty` 读取确认，使 `curl | bash` 场景也能正常交互，
   不消费安装脚本的管道输入。
4. 用户确认后，安装脚本先完成退出，再由短生命周期的后台 Helper 执行重启。
   这样可以避免安装命令由 Codex 或 Claude Code 发起时，客户端提前杀死安装进程。
5. 用户拒绝或不存在控制终端时，不停止任何客户端，只输出手动操作说明。

## 重启语义

### Codex Desktop

macOS 下先请求 `ChatGPT.app` 正常退出，最多等待 10 秒确认原 PID 消失后重新打开。
若等待超时则不强行终止，也不重复打开 Codex Desktop；安装前没有运行时，不主动启动。

Windows Codex Desktop 的可执行文件和官方重启方式尚未验证，首版不自动重启。

### Codex CLI 与 Claude Code CLI

安装脚本无法安全地把 CLI 重新挂载到原终端，也无法可靠恢复会话和未发送内容。
因此用户确认后，后台 Helper 会在安装脚本退出后，向正在运行的 CLI 进程发送正常
终止信号。只处理带 TTY 的交互式 CLI，不处理后台任务或服务；完成提示会要求用户在
需要的终端重新执行 `codex` 或 `claude`。

安装脚本不自动打开新终端窗口，也不猜测终端类型、工作目录、启动参数或会话恢复参数。

## 命令兼容性

不提供任何重启参数或环境变量。正常安装完成后默认询问；用户确认则立即执行，拒绝则
稍后手动重启。原有 `--restart-codex`、`--no-restart-codex` 和
`GESTA_RESTART_CODEX` 全部删除。

现有无人值守安装默认不受影响：没有控制终端时，默认只提示手动重启，不停止进程。
已经发布的不可变安装包不会修改；新行为仅从下一版 Agent 开始生效，公共 Bootstrap
继续按照当前逻辑选择 Stable 或 RC 版本。

## 安全与失败处理

- 没有交互确认时，绝不停止客户端。
- 只匹配目标用户的、名称精确的受支持进程，不做宽泛的字符串包含匹配。
- 优先正常终止并设置最大等待时间；重启失败只提示，不把已成功的 Gesta 安装标记为失败。
- 不终止安装脚本或重启 Helper 自身。
- 不输出 API Key、进程环境变量或完整命令行。
- 无法检测进程时，降级为手动重启提示。

## 性能与规模

该流程每次安装只执行一次，并且只检查本机目标用户的进程表。运行时间和内存使用量
受本机进程数量限制；不会新增 Daemon 轮询、持久化状态、网络请求或控制面负载。
组织规模和数据量增长不会带来额外的持续压力。

## 实现范围

- `scripts/install.sh`：交互确认、POSIX 进程检测、后台重启 Helper
  和手动提示。
- 增加针对提示、非交互行为、精确进程匹配和后台执行的定向测试。
- 通过现有不可变 Agent Artifact 发布流程生成安装包，不手工修改
  `onboard/artifacts/agent/` 下的生成文件。

## 验收标准

- 文档中的 `curl | bash` 安装方式能够通过控制终端询问用户。
- 用户拒绝后不影响任何客户端，并展示手动操作步骤。
- 用户确认后不会在安装成功退出前中断安装进程。
- macOS 上正在运行的 Codex Desktop 能正常退出并重新打开。
- 正在运行的 Codex CLI 和 Claude Code CLI 能正常退出，并明确提示用户启动新会话。
- 非交互安装不停止任何客户端。
- 客户端重启失败不会回滚或破坏已经成功的 Agent 安装。

## 已确认决策

1. 首版只覆盖 macOS/Linux，不修改 Windows 安装脚本。
2. 不新增重启参数，正常安装默认询问。
3. 删除所有 Codex 专用重启参数和环境变量，不保留兼容入口。
4. 用户确认后关闭 CLI 会话，由用户重新执行 `codex` 或 `claude`；不自动打开新终端。
